# Digit Recognition Tools

This directory is reserved for offline tools used to generate data, train models, and test models for digit recognition.

Runtime ROS2 nodes and GUI scripts should not be placed here. Runtime Python nodes belong in `scripts/`.

This directory is not installed into the ROS2 install space by default.

Future tools can be added here, for example:

- `generate_training_data.py`
- `train_model.py`
- `test_model.py`
